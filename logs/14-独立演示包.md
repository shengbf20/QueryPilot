# 14：独立演示包 QueryPilot-demo

> 记录范围：仓库内可单独带走的演示目录 `QueryPilot-demo/`——双击即可起问数 + 对话，不依赖主仓库其余文件，也不改 `ask()` 编排。  
> 记录时间：2026-08-26  
> 状态：✅ 可演示  
> 对照：主仓库开发入口仍是 `querypilot serve` + `frontend/`（`logs/05`、`logs/10`）；本目录是**副本打包**，不是第二条实现。

---

## 1. 要解决什么

评测、开发、改元数据仍在仓库根目录。演示需要另一条路径：拷走一个文件夹就能跑，评委/同事不必 `import_data`、不必起 Vite、不必知道 CLI。

因此做成**自包含副本**，而不是从根目录再挂一套入口：

- 主仓库继续承担 eval / CLI / table_ops / 源码前端；
- demo **复制**热路径代码与元数据，并带上已导入的 DuckDB 与前端构建产物。

不把 Agent 编排折进 `ask()`。问数仍是 `ask()`，对话仍是 `querypilot.agentic.run`。

---

## 2. 怎么用

1. 进入 `QueryPilot-demo/`，双击 **启动演示.bat**（仅此一个入口；曾有功能相同的 `start.bat`，已删）。
2. 首次会建 `.venv` 并装 `requirements.txt`。需本机已有 Python 3.10+ 且能上网。
3. 本窗口跑 `python.exe demo_server.py`（不要用 `pythonw`：看不到报错，窗口会闪退）。
4. 浏览器打开 `http://127.0.0.1:8787/`。关掉该窗口即停服务。
5. 右上角 **设置**：接口地址、模型名、API Key。写入本目录 `.env`，界面只显示掩码。

建议问句见目录内 `使用说明.md`。问数应出 SQL 与结果表；对话应能追问。

端口固定 **8787**，避免和主仓库 `querypilot serve :8000` 撞车。只有首页 HTML 含 `QueryPilot` 才视为「本演示已在跑」并复用；否则提示端口被占用。

`启动演示.bat` **只含 ASCII**（命令与提示都是英文）。cmd 默认按 GBK 拆行，文件里一旦出现 UTF-8 中文，就会被拆成 `install` / `xit` 之类的假命令。中文说明放在 `使用说明.md` 和 Python 里。

---

## 3. 目录里有什么 / 没有什么

| 路径 | 作用 |
|------|------|
| `启动演示.bat` | 双击入口；本窗口保活 |
| `demo_server.py` | 切工作目录、补 `.env`、开浏览器、uvicorn |
| `querypilot/` | 热路径副本：agent / agentic / api / cache / db / llm / metadata_engine / safety |
| `metadata/` | 表 YAML、join_graph、metrics、few-shot、pruning |
| `db/competition.duckdb` | 已导入的只读库（根 `.gitignore` 对主库忽略 `*.duckdb`，对本路径放行） |
| `ui/` | `frontend/` 的 Vite 构建产物，同一端口静态挂载 |
| `.env.example` | Key / 地址 / 模型占位；首次启动可复制为 `.env` |
| `使用说明.md` | 给演示对象看的短说明 |

**故意不带**：`querypilot/eval`、`cli`、`table_ops`、`onboarding`、`data/` CSV、`tests/`、Vite 源码。评测与改前端仍回主仓库。

密钥：本目录 `.env` 与根目录一样不提交。设置页 `GET/PUT /api/settings` 读写的是**当前进程 + 本目录 `.env`**，不是硬编码。

## 4. 与主仓库的关系

| 项 | 主仓库 | Demo |
|----|--------|------|
| 问数 | `ask()`，默认 `mode=fast` | 同左（副本） |
| 对话 | `agentic.run`，`mode=agent` + `session_id` | 同左（副本） |
| UI 开发 | `frontend/` + Vite `:5173`，API `:8000` | 已构建的 `ui/`，单端口 8787 |
| 改 Python | 改根目录 `querypilot/`，跑 pytest | 改完后**再复制**对应文件到 `QueryPilot-demo/querypilot/` |
| 改界面 | 改 `frontend/` 后 `npm run build`，再覆盖 `ui/` | 不维护第二份 React 源码 |

副本不是 symlink。主仓库修了对话耗时、设置页、围栏等，不同步则演示仍是旧行为。

---

## 5. 对话页耗时（2026-08-26）

对话走 Agent 时，原先只写墙钟 `total_ms`，剪枝 / 生成 / L1 / L2 / 执行 / 探针都是 0。

第一次详情若正常，多半是从问数页带入的 `ask()` 结果（分项齐全）；后续轮次是 `run()`，合计对、分项全 0。

已在 `agentic` 上按阶段累加，主仓库与 demo 副本都改了：`refresh_schema` / `search_schema` → `prune_ms`，`chat()` → `generate_ms`，`run_sql` 各段 → L1 / L2 / 执行 / 探针。`total_ms` 仍是整轮墙钟。`ask()` 编排未动。

## 6. 踩过的坑（启动）

| 现象 | 原因 | 处理 |
|------|------|------|
| 双击窗口立刻没了 | 用了 `pythonw`，或端口判断把主仓库 `:8000` 当成自己 | 本窗口 `python.exe`；演示只认 **8787** 且首页含 QueryPilot |
| 中文提示变成乱码 / `install` 不是命令 | bat 含 UTF-8 中文，cmd 按 GBK 截断 | 启动脚本保持纯 ASCII |
| 两个 bat 不知点哪个 | `start.bat` 与 `启动演示.bat` 相同 | 只留 `启动演示.bat` |

## 7. 验收（手测即可）

- 只带 `QueryPilot-demo/` 到另一台已装 Python 的机器，双击能打开 8787。
- 设置里保存 Key 后，问数出表；对话能追问，详情分项与合计都有数。
- 主仓库 `querypilot serve :8000` 同时开着时，演示仍走 8787，互不顶替。
