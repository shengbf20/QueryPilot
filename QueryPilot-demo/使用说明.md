# QueryPilot 演示包

本目录可单独使用，不依赖仓库其余文件。

## 怎么测

1. 双击 **启动演示.bat**（首次会自动装依赖，需已安装 Python 3.10+ 且能上网）。
2. 会留下一个标题为 QueryPilot Demo 的窗口，浏览器打开 `http://127.0.0.1:8787/`。关掉该窗口即停止服务。
3. 点右上角 **设置**，填写接口地址、模型名、API Key，点保存。
4. **问数**：自然语言取数（快路径）。**对话**：多轮工具循环。

不必改任何文件或敲命令。密钥只保存在本目录 `.env`，界面只显示掩码。

## 建议问句

- 有多少年龄大于30岁的女性客户？
- 学历本科及以上的男性客户，年龄大于50岁的有多少个
- 帮我看看客户情况

问数应出结果表和 SQL；对话应能追问。配错 Key 时设置里保存仍成功，发送后会看到接口报错。

## 目录里有什么

| 路径 | 作用 |
|---|---|
| `启动演示.bat` | 双击入口（窗口需保持打开） |
| `ui/` | Chat UI |
| `querypilot/` | 本包内的取数与对话后端（副本） |
| `metadata/` | 表/指标/口径 |
| `db/competition.duckdb` | 本地只读库 |
