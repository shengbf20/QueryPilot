新表登记

填写这张表的业务含义，提交后即可用于提问。

选择表

表需要已经导入本机数据库。把数据文件放进模拟数据目录后，用项目里的导入命令写入，再回到这里填写表名。

基本信息

关键词用逗号分隔。问句里出现这些词时会选中这张表，请写专属说法，不要用「客户」这类太宽的词。

一行是什么：例如一位客户、一位客户经理、一笔持仓。

补充说明用来记下容易弄错的口径，例如日期只是快照、和其他表关联时不要带上日期。

每列是什么意思

左边是列名，右边用业务语言填写。每一列都要填。

和哪些表有关

勾选要保留的关联，没勾的不会保存。百分比表示这列的取值有多少能在对方表里找到。标成「推荐」的会默认勾上。

编码是什么意思

已经对上公共编码的列会直接列出含义。还没有对照的编码，请逐个填写中文意思。

试一句

用一句真实问法试查这张表。句子里要带上上面的关键词或业务名称，提交后会检查能否选中它。
